# 运维用户操作手册

> - 文档编号：CIDAS-UM-OPS-001
> - 版本：V1.0
> - 发布日期：2026-11-22
> - 适用角色：运维人员

---

## 1 引言

### 1.1 手册说明

本手册面向学校运维人员，说明如何使用运维工作台、用户与权限、审计与安全、消息与告警以及个人中心。

### 1.2 运维人员能做什么

- 查看用户、文档、风险事件与存储占用等整体情况；
- 查看用户目录、账号状态与登录记录；
- 冻结或解冻学生、教师账号；
- 检索审计记录并查看事件详情；
- 查看消息与告警；
- 维护个人账号与安全设置。

### 1.3 读者与适用范围

- 适用读者：学校系统运维人员；
- 适用终端：桌面浏览器（Chrome / Edge / Safari）；
- 不涉及：教师课程模板与作业批改、学生个人文档操作。

---

## 2 使用前准备

### 2.1 登录

1. 打开学校提供的系统访问地址。
2. 输入运维账号与密码，点击「登录」。
3. 在「身份认证成功」页点击「进入工作台」。
4. 首次登录后，建议进入「个人中心 → 账号与安全」修改初始密码。
5. 运维账号必须开启双因素认证；关闭时系统会提示不能关闭。

### 2.2 认识界面

左侧导航包括：运维工作台、课程治理、用户与权限、审计与安全、存储与资源、消息与告警、个人中心。

---

## 3 运维工作台

工作台提供以下统计：

- 用户总数；
- 文档总数；
- 近 7 天高风险事件；
- 存储占用率。

页面下方还会展示风险事件、系统状态、待办审批等内容。部分区域为演示展示，实际以页面提示为准。

---

## 4 用户与权限

### 4.1 用户目录

1. 进入「用户与权限」→「用户目录」。
2. 可按角色、账号状态、关键字筛选。
3. 表格显示账号、姓名、角色、组织、账号状态、最近登录时间等信息。
4. 点击用户行可以查看权限详情与最近访问记录。

### 4.2 冻结与解冻账号

1. 在用户行点击「冻结」或「解冻」。
2. 确认后系统会执行操作。
3. 冻结后该账号无法登录；已登录的账号在后续操作时会被拒绝。
4. 解冻后账号可以重新登录。
5. 不能冻结自己，也不能冻结其他运维账号。

### 4.3 角色权限矩阵与新增用户

「角色权限矩阵」、新增用户、新增自定义角色等入口当前为演示展示，操作不会写入正式数据。真实角色与权限以系统内置设置为准。

---

## 5 审计与安全

### 5.1 检索审计记录

1. 进入「审计与安全」→「操作日志」。
2. 选择时间范围：最近 24 小时、7 天或 30 天。
3. 可按对象类型和关键字筛选。
4. 点击「检索」查看结果。

### 5.2 查看事件详情

点击审计记录行可以查看：

- 事件编号、发生时间、风险等级、处理结果；
- 操作者、操作账号、来源地址、终端；
- 操作对象、结果编号；
- 事件链路与影响面。

### 5.3 其他页签

「安全事件」「权限冲突」「访问策略」页签当前为演示内容，实际以页面提示为准。

---

## 6 消息与告警

1. 进入「消息与告警」。
2. 可按「全部 / 未读 / 已读」和消息类型筛选。
3. 可以标记已读/未读，或一键全部已读。
4. 告警、审批类消息预留给后续版本，当前可能没有数据。

---

## 7 个人中心

- **个人资料**：查看姓名、账号、角色、组织等信息；实名信息由学校统一提供，只读。
- **账号与安全**：修改登录密码；查看双因素认证、新设备登录提醒、通知偏好、当前会话和登录记录。
- 运维账号必须保持双因素认证开启。
- 修改密码后需要重新登录。

---

## 8 课程治理与存储资源

- **课程治理**：查看课程状态、成员规模、模板关联与教学运行指标；新建课程、成员导入、归档等操作当前为演示展示，真实课程管理请在教师端操作。
- **存储与资源**：存储与回收站、系统状态、配置变更记录当前为演示展示；清理、恢复、回滚只在页面上演示，不影响真实数据。

---

## 9 常见提示与处理

| 提示/现象 | 处理 |
| --- | --- |
| 无法冻结账号 | 不能冻结自己或其他运维账号；确认目标账号状态 |
| 冻结后账号仍能操作 | 账号在后续操作时会被拒绝；如仍异常，请让用户刷新或重新登录 |
| 看不到某些菜单 | 菜单受运维账号权限控制；联系系统负责人确认权限 |
| 审计记录为空 | 调整时间范围、对象类型或关键字后重新检索 |
| 消息列表为空 | 当前可能没有新消息；告警、审批类消息为后续版本内容 |
| 不能关闭双因素认证 | 运维账号必须保持开启，这是安全要求 |
| 课程治理/存储页面数据与实际不一致 | 这些页面当前为演示展示，实际以教师端或正式数据为准 |

---

## 10 使用限制

- 仅支持桌面浏览器；
- 用户目录与冻结/解冻为真实操作；角色权限矩阵写操作、课程治理、存储清理、系统状态、安全事件/访问策略等为演示内容；
- 运维账号必须保持双因素认证开启；
- 审计记录按时间范围和筛选条件查询，超出范围的内容不会被列出。

## 附录 A 账号状态

| 状态 | 含义 |
| --- | --- |
| 正常 | 可以正常登录 |
| 冻结 | 不能登录，已登录会话在后续操作时被拒绝 |
| 未激活 | 尚未完成首次登录激活 |
| 锁定 | 因安全原因暂时不能登录 |

## 附录 B 术语

| 术语 | 说明 |
| --- | --- |
| 冻结 | 暂停账号登录与操作 |
| 解冻 | 恢复账号登录与操作 |
| 审计记录 | 系统记录的关键操作与结果 |
| 高风险事件 | 需要重点关注的安全或异常操作 |
| 双因素认证 | 登录时增加一道验证步骤 |
