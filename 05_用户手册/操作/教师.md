## 1 引言

### 1.1 手册说明

本手册面向使用校园智能文档助手的教师，说明如何创建课程、导入学生、维护课程模板、发布作业、查看提交统计以及批改反馈。

### 1.2 教师能做什么

- 创建课程并导入学生名单；
- 查看课程学生与课程组信息；
- 创建、编辑、发布课程模板；
- 指定模板并发布作业，支持携带 Word 附件；
- 查看作业提交统计，提醒未提交学生；
- 逐项评分并填写反馈；
- 管理自己的教学文档，使用智能处理与格式检查；
- 邀请协作者、生成只读共享链接；
- 查看消息通知与个人账号信息。

### 1.3 读者与适用范围

- 适用读者：承担课程教学任务的教师；
- 适用终端：桌面浏览器（Chrome / Edge / Safari）；
- 不涉及：学生个人文档操作细节、运维账号管理、学校系统设置。

> 学生端的文档阅读、编辑、智能处理与作业提交说明见《学生用户操作手册》。

## 2 使用前准备

### 2.1 登录

1. 打开学校提供的系统访问地址。
2. 输入账号与密码，点击「登录」。
3. 在「身份认证成功」页点击「进入工作台」。
4. 首次登录后，建议进入「个人中心 → 账号与安全」修改初始密码。
5. 演示时建议教师使用普通窗口、学生使用隐身窗口，避免在同一窗口反复切换账号。

### 2.2 认识界面

教师端左侧导航包括：工作台、我的文档、智能处理、格式与模板、课程模板、协作与版本、课程与作业、消息通知、个人中心。

常用入口：

- **工作台**：查看本周临近截止作业、待批改提交、格式异常提交等；
- **课程与作业**：课程管理、作业与提交统计、批改与反馈；
- **课程模板**：维护课程模板与规则版本；
- **我的文档**：上传、阅读、编辑教学文档。

### 2.3 文件要求

| 类型 | 要求 |
| --- | --- |
| 文档上传 | Word（`.doc` / `.docx`）或 PDF，单个文件不超过 20MB |
| 课程模板 | Word（`.docx`） |
| 作业附件 | Word（`.docx`），单个不超过 20MB，可上传多个 |
| 成员名单 | CSV 文件，首行包含学号、姓名、课程组 |

> 上传失败时，先检查文件格式、大小和网络；仍失败请联系学校系统管理员。

## 3 课程管理

### 3.1 新建课程

1. 进入「课程与作业」→「课程管理」。
2. 点击右上角「新建课程」。
3. 填写课程名称、课程代码、学期。
4. 「默认文档权限」保持默认即可。
5. 点击「创建课程」。课程代码与学期组合不能重复；重复时系统会提示，请更换课程代码。

### 3.2 成员导入

1. 在课程行点击「成员导入」。
2. 上传学生名单 CSV 文件；首行需要包含 `学号、姓名、课程组`。
3. 在「导入预览」中核对解析出的学生行。
4. 点击「确认导入」。
5. 查看导入结果：新建账号、激活入组、已在课程、失败行。
6. 导入完成后，学生刷新「课程与作业」即可看到课程。

> 名单中的学号即学生登录账号；没有账号的学生会先建立未激活账号，由学生首次登录时激活。

### 3.3 查看课程学生

- 课程列表显示学期、课程名、负责人、课程组、学生数、运行状态、本周截止数。
- 点击「学生数」下方的「查看所有学生」，会弹出「全部学生」窗口，显示学号、姓名、课程组。
- 窗口关闭后回到课程列表，不会影响当前筛选条件。

### 3.4 课程筛选

- 可按「全部 / 进行中 / 已归档」筛选课程。
- 可输入课程名或课程代码搜索。
- 已归档课程为只读，不能再进行成员导入等操作。

## 4 课程模板

### 4.1 模板列表与新建

1. 进入「课程模板」。
2. 可按课程筛选模板。
3. 点击「新建模板」，选择课程，填写模板名称与说明。
4. 创建后进入模板编辑窗口。

模板状态：

| 状态 | 含义 |
| --- | --- |
| 草稿 | 还没有发布，学生不可见 |
| 已发布 | 学生可以选择该模板 |
| 已停用 | 学生不能再选择，历史绑定不受影响 |

### 4.2 编辑模板

1. 在模板列表点击「编辑」。
2. 可以选择已有版本查看规则，或上传 Word 模板文件预览解析结果。
3. 上传 Word 后，系统会尝试解析出格式规则；确认后才生成新版本。
4. 规则按格式类型分组，例如：字体、字号、行距、页边距、题注、代码块、参考文献、页眉页脚。
5. 点击「添加规则」可以补充规则；每条规则可选择作用对象并填写要求。
6. 如页面提供「高级配置」入口，建议在熟悉规则时使用；不熟悉时保持默认设置。
7. 保存前系统会检查规则是否完整；有错误会在页面上列出，请按提示修正。
8. 点击「保存规则」保存当前未发布版本。

> 已发布版本的规则是只读的，不能直接修改；如需调整，请基于已发布版本另存新版本。

### 4.3 发布模板

1. 点击「发布确认」。
2. 核对模板名称、版本、适用范围和变更说明。
3. 确认发布后，学生端可以使用该模板。
4. 发布后的模板会生成版本记录；历史版本保留。

### 4.4 版本历史与另存新版本

- 在编辑窗口可以查看版本历史：版本号、状态、发布时间、变更说明。
- 已发布版本不能直接修改。
- 点击「基于此版本编辑另存新版本」，会生成一个未发布的新版本，原发布版本保持不变。
- 新版本确认无误后再发布。

### 4.5 停用、启用与删除

- 已发布模板可以「停用」，停用后学生不能再选择，但历史绑定不受影响。
- 已停用模板可以「重新启用」。
- 草稿模板可以删除。

## 5 作业

### 5.1 发布作业

1. 进入「课程与作业」→「作业与提交统计」。
2. 点击「发布作业」。
3. 填写或选择：
   - 所属课程；
   - 指定模板（可选）；
   - 作业附件（可选，仅 Word `.docx`，不超过 20MB，可多个）；
   - 作业标题、作业要求、截止时间；
   - 提交格式（Word / PDF / Word 或 PDF）；
   - 是否允许迟交；
   - 是否要求格式检查（提交后显示检查结论，当前不会阻止提交）；
   - 评分标准（默认 5 项，每项 20 分，总分 100）。
4. 右侧「学生端预览」可以核对标题、课程、截止时间、模板和评分标准。
5. 点击「确认发布」，学生端「课程与作业」即可看到作业。

> 作业附件用于给学生提供参考文件；学生可以下载附件，也可以在附件基础上生成自己的可编辑文档。

### 5.2 作业与提交统计

作业列表显示：

- 应交、已交、逾期人数；
- 格式异常数；
- 已批改数；
- 提交率；
- 作业状态（草稿 / 已发布 / 已截止）。

可按课程筛选作业。

### 5.3 提醒未提交学生

1. 在作业行点击「提醒未提交学生」。
2. 查看未提交名单。
3. 点击「发布提醒」，系统会向名单中的学生发送站内消息。
4. 同一学生、同一作业、同一天只会提醒一次。

## 6 批改与反馈

1. 进入「课程与作业」→「批改与反馈」。
2. 可按课程、学号或姓名、提交状态筛选。
3. 点击左侧提交行，右侧显示评分表单。
4. 按评分标准逐项打分；总分由系统计算。
5. 「反馈意见」为选填：只打分也可以提交，留空不会报错。
6. 点击「保存并反馈」。
7. 已批改的提交为只读，不能重复修改。

> 学生提交后可多次提交，批改列表以最新一次提交为准。

---

## 7 我的文档与智能处理

教师端「我的文档」与学生端基本一致，区别：

- 上传文档时必须选择课程；
- 文档列表会显示所属课程；
- 可以查看其他教师共享给你的「协同」文档，协作者视角只能批注、问答和格式检查；
- 文档阅读、编辑、智能处理、格式检查、批注、共享与版本操作，与学生端说明一致，见《学生用户操作手册》第 3 章。

教师上传文档时请选择正确的课程，学生端作业提交会校验文档是否属于该课程。

## 8 协作与共享

### 8.1 邀请协作者

1. 在「我的文档」中点击文档行的「共享」。
2. 在「邀请协作者」区域搜索课程教师或学生。
3. 选择成员后点击「邀请」。
4. 被邀请成员会在自己的「我的文档」中看到「协同」文档，可批注、问答和格式检查。
5. 可以在同一窗口中移除协作者。

### 8.2 共享链接

- 可以生成只读链接，设置有效期（如 1 天、7 天、30 天）。
- 复制链接后，其他人在浏览器打开即可阅读，无需登录。
- 链接是只读的，不能编辑。
- 可以随时撤销链接；撤销后链接立即失效。

## 9 消息与个人中心

### 9.1 消息通知

- 查看学生提交、格式异常、系统提醒等消息。
- 可以按「全部 / 未读 / 已读」和消息类型筛选。
- 可以标记已读/未读，或一键全部已读。
- 带「前往处理」的消息可以跳转到相关作业或文档。

### 9.2 个人中心

- **个人资料**：查看姓名、账号、角色、组织等信息；实名信息由学校统一提供，只读。
- **账号与安全**：修改登录密码；查看双因素认证、新设备登录提醒、通知偏好、当前会话和登录记录。
- 修改密码后需要重新登录。

## 10 常见提示与处理

| 提示/现象 | 处理 |
| --- | --- |
| 新建课程提示「课程代码重复」 | 同一学期内课程代码不能重复，请更换课程代码或复用已有课程 |
| 成员导入失败 | 检查名单文件是否为 CSV、首行是否包含学号/姓名/课程组；确认文件没有损坏 |
| 学生看不到课程 | 确认成员导入成功；让学生刷新页面；检查学生账号是否已激活 |
| 模板上传后没有解析出规则 | 确认文件是 Word `.docx`；可以手工添加规则后保存 |
| 模板保存提示规则错误 | 按页面提示修正规则配置；不熟悉时使用默认规则 |
| 模板无法修改 | 已发布版本只读；请基于该版本另存新版本 |
| 作业附件上传失败 | 检查文件是否为 `.docx`、是否超过 20MB |
| 学生提交失败 | 确认学生是该课程成员、文档已就绪且属于该课程 |
| 批改保存失败 | 检查每项分数是否在 0 到满分之间；刷新后重新载入评分标准 |
| 学生没有收到提醒 | 提醒会发送站内消息；同一学生同一天只提醒一次，请让学生查看消息通知 |
| 上传文档失败 | 检查文件格式、大小和网络；仍失败联系学校系统管理员 |
| 看不到某些菜单 | 菜单受账号权限控制；联系学校系统管理员确认权限 |

## 11 常见问题与限制

| 问题 | 回答 |
| --- | --- |
| 作业可以同时带模板和附件吗？ | 可以。模板用于规定格式与结构，附件用于提供参考文件 |
| 学生能在附件基础上编辑吗？ | 可以。学生在提交弹窗中点击「基于附件编辑」，会生成一份自己的可编辑文档 |
| 一键修复会修改模板吗？ | 不会。修复只影响学生自己的文档版本，不修改课程模板 |
| 模板发布后还能改吗？ | 已发布版本只读；请另存新版本后再发布 |
| 学生提交后还能再提交吗？ | 可以；以最新一次提交为准，教师批改列表显示最新提交 |
| 批改后还能改分吗？ | 已批改提交只读，不能重复修改 |
| 支持在手机上使用吗？ | 本期仅支持桌面浏览器 |
| 共享链接可以批注吗？ | 共享链接是只读的；需要批注请邀请协作者 |

**使用限制**

- 仅支持桌面浏览器；
- 文档、模板和附件上传需要网络正常；
- 课程模板的自动解析以实际文件为准，解析不完整时可以手工补充规则；
- 共享链接为只读，协作者默认只能批注、问答和格式检查。
