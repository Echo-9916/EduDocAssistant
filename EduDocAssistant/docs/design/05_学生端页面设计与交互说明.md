# 学生端页面设计与交互说明

> 学生路线 v3 的可交互源稿与 27 屏预览位于 `03_页面原型/student_route_v3/`。
>
> 原版学生端 27 个基础画面及其学生专属交互已从 Figma 删除。当前只保留 v3 的 27 屏和总览，角色总览中的学生入口已指向 v3 总览。

## v3 学生路线

文档接入 → 智能处理 → 格式与模板 → 协作与版本 → 作业与交付 → 消息与个人中心。

学习工作台 → 我的文档 → 上传文档 → 文档处理进度 → 文档预览 → 文本摘要 → 要点提取 → 文档问答 → 问答无依据拒答 → 文本润色 → 课程模板 → 代码与图表规范化 → 格式规范校验 → 一键修复确认 → 格式转换 → 协作编辑 → 版本记录 → 版本对比 → 恢复版本确认 → 共享设置 → 添加协作者 → 导出文档 → 下载中心 → 学生作业列表 → 提交学生作业 → 消息中心 → 个人资料。

## 需求依据

学生以本人文档和共享协作文档为工作对象，可查看本人及共享文档、编辑本人及协作文档、删除本人文档，并可参与小组协作和提交作业。学生不承担模板维护、角色权限管理和审计职责。模板由教师按课程发布，学生新建文档时选择课程模板，提交前使用格式校验。

依据：

- `02_需求规格说明/需求规格说明书.docx`
- `05_系统设计/03_详细设计说明书.docx`

## 学生导航

学生端一级导航固定为：

1. 工作台
2. 我的文档
3. 智能处理
4. 格式与模板
5. 协作与版本
6. 课程与作业
7. 个人中心
8. 消息通知

学生端不设置“课程模板库”一级导航。课程模板作为“格式与模板”内的只读入口，学生可查看课程要求或按模板新建文档，不显示新建、导入、编辑、发布和版本维护操作。

“协作与版本”属于学生必要能力，用于小组邀请、权限设置、共同编辑、版本对比和恢复。

## 页面任务

| 页面 | 学生任务 | 主要交互 |
| --- | --- | --- |
| 学生学习工作台 | 查看待办、最近文档和继续处理入口 | 打开文档、进入作业、继续智能处理 |
| 我的文档 | 查找和管理本人文档 | 筛选、搜索、上传、重命名、复制、删除、导出 |
| 上传文档 | 上传 Word/PDF 并指定课程和类型 | 拖放、多选、错误提示、断点续传 |
| 文档处理进度 | 查看解析和处理阶段 | 等待、取消、失败重试、后台继续 |
| 文档预览 | 浏览章节和正文 | 翻页、缩放、目录跳转、关键词高亮 |
| 代码与图表规范化 | 处理代码块、图表编号和题注 | 识别语言、保留缩进、自动编号、更新引用 |
| 文本摘要 | 快速理解长文档 | 生成、重新生成、原文定位、复制、导出 |
| 要点提取 | 获取并定位关键要点 | 勾选、复制、按原文顺序导出 |
| 文档问答 | 围绕当前文档提问 | 提交问题、查看引用、连续追问、拒答 |
| 问答无依据拒答 | 识别无法溯源的问题 | 返回文档、换一种问法 |
| 文本润色 | 改善选定段落表达 | 原文对照、部分采纳、撤销、冲突提示 |
| 课程模板 | 查看已发布课程模板 | 查看要求、按模板新建文档 |
| 格式规范校验 | 按课程模板检查提交格式 | 查看问题、原文定位、重新校验 |
| 一键修复确认 | 确认可自动修复的问题 | 选择修复项、确认、生成新版本 |
| 格式转换 | 转换 Word/PDF | 选择目标格式、查看进度、下载结果 |
| 协作编辑 | 与小组共同编辑文档 | 邀请成员、权限设置、在线光标、自动保存 |
| 版本记录 | 查看历史保存记录 | 查看版本信息、选择对比或恢复 |
| 版本对比 | 查看不同版本差异 | 新增、删除、修改内容标记 |
| 恢复版本确认 | 确认恢复历史版本 | 恢复为新版本、取消 |
| 共享设置 | 控制文档访问范围 | 本人、指定成员、课程范围、链接权限 |
| 添加协作者 | 邀请协作者 | 搜索账号、选择可编辑/评论/查看 |
| 导出文档 | 导出当前处理结果 | 选择范围、格式、生成任务 |
| 下载中心 | 获取转换和导出结果 | 下载、删除记录、失败重试 |
| 学生作业列表 | 查看课程作业状态 | 查看截止时间、进入提交、查看反馈 |
| 提交学生作业 | 提交当前文档版本 | 选择版本、提交前校验、确认提交 |
| 消息中心 | 查看任务和教学通知 | 筛选、标为已读、进入关联页面 |
| 个人资料 | 维护本人账号信息 | 编辑资料、修改密码、通知偏好、回收站 |

## 版式规范

- 页面标题 24/32，模块标题 18/26，卡片标题 15/22。
- 正文 12/18，辅助文字 11/16，最小内容字号 11 px。
- 页面边距 32 px，卡片内边距 16 px，表单行间距 12 px。
- 页面标题区域与内容区分离，标题、面包屑和右侧操作不得互相遮挡。
- 表格行高不少于 44 px，长文本自动换行。
- 文本超出安全区域时自动调整宽度，不通过缩小字号规避问题。
- 页面内容统一从顶部栏下方重新建立内容层，旧版 SVG 的绝对坐标文字不参与新布局。
- 上传、处理进度、一键修复、恢复版本和添加协作者使用独立遮罩与弹窗面板，底层页面文字不参与弹窗排版。
- 双栏和三栏页面先划分固定区域，再放置标题、正文、设置与操作，避免逐段文字避让造成组件错位。
- 内容区重建后删除旧版遗留文字、重复图层、隐藏交互层和空容器，不再通过隐藏节点维持页面。
- 课程模板页采用学生只读语义，只提供“查看要求”和“按模板新建”，不出现编辑、发布或模板版本维护操作。
- 工作台快捷入口只保留上传、按模板新建、查看作业和教学消息，不出现教师或管理员能力。
