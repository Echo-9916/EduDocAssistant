# 路线画面图层归组与命名规范

本规范把登录页（`AUTH_DESIGN.md`）的“语义分区 + 中文命名 + 热点命名”规则推广到 81 个路线画面。2026-10-30 已应用到全部画面，Figma 版本 `2416111651714900099`。

## 画板顶层

每个 1440×900 路线画面固定为三层：

```text
[画面画板] 学生路线 v3 / 01 学习工作台
├─ 总画布      页面底色
├─ 侧边栏      左侧导航区（等价登录页 Left）
└─ 内容区      右侧工作区（等价登录页 Right）
```

## 热点规则

- 认证页沿用 `Hotspot / 操作名称`。
- 路线画面按既定口径不设置跨页跳转与热点，页内交互控件保留为真实控件命名。
