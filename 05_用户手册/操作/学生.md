## 1 引言

### 1.1 手册说明

本手册面向使用校园智能文档助手的学生，说明如何登录、管理文档、阅读与编辑、使用智能处理、完成格式检查、提交作业以及查看反馈。

### 1.2 系统能为你做什么

- 上传并阅读 Word / PDF 文档；
- 按标题、正文、列表、表格、代码、图片查看文档内容；
- 编辑文档并保存为新版本；
- 使用摘要、要点、问答、润色等智能处理；
- 检查文档格式并按提示修复；
- 查看教师发布的作业、按模板或附件准备文档并提交；
- 查看批改反馈、消息通知；
- 与同学/教师协作批注，或分享只读链接。

### 1.3 读者与适用范围

- 适用读者：在校学生；
- 适用终端：桌面浏览器（Chrome / Edge / Safari）；
- 不涉及：教师课程管理、运维账号管理、学校系统设置。

## 2 使用前准备

### 2.1 登录

1. 打开学校提供的系统访问地址。
2. 输入账号与密码，点击「登录」。
3. 在「身份认证成功」页点击「进入工作台」。
4. 首次登录后，建议进入「个人中心 → 账号与安全」修改初始密码。
5. 使用完毕后，点击右上角头像菜单中的「退出登录」。

> 账号由学校或教师提供；账号被冻结、未激活或密码错误时无法登录，请联系教师或管理员。

### 2.2 认识界面

- **左侧导航**：工作台、我的文档、智能处理、格式与模板、协作与版本、课程与作业、个人中心、消息通知。
- **顶部**：当前页面标题、筛选与操作按钮。
- **右侧**：文档预览页的智能处理面板。
- **消息通知**：查看作业提醒、批改反馈、格式异常等消息。

### 2.3 文件与图片要求

| 类型 | 要求 |
| --- | --- |
| 文档上传 | Word（`.doc` / `.docx`）或 PDF，单个文件不超过 20MB，可一次选择多个 |
| 文档内图片 | PNG / JPEG / GIF / WEBP，单张不超过 10MB |
| 提交文档 | 必须是本人上传或创建、已完成处理、属于当前课程的文档 |

> 上传失败时，先检查文件大小、文件格式和网络；仍失败请联系教师或管理员。

### 2.4 状态说明

**文档状态**

| 标签 | 含义 |
| --- | --- |
| 上传中 | 文件正在上传 |
| 解析中 | 系统正在读取文档内容 |
| 就绪 | 可以阅读、编辑、检查格式与提交 |
| 解析失败 | 无法读取文档，可在列表中重新解析 |
| 已提交 | 已作为作业提交 |
| 已归档 | 只读归档 |
| 已删除 | 在回收站，可恢复 |

**格式检查结论**

| 标签 | 含义 |
| --- | --- |
| 未校验 | 还没有检查过格式 |
| 通过 | 没有发现问题 |
| 警告 | 有提醒项，建议修改 |
| 阻塞 | 有需要处理的问题 |

**作业状态**

| 标签 | 含义 |
| --- | --- |
| 待提交 | 尚未提交 |
| 已提交 | 已提交，等待教师批改 |
| 已批改 | 教师已评分 |
| 逾期 | 已过截止时间，仍未提交 |

## 3 我的文档

### 3.1 上传文档

1. 进入「我的文档」，点击右上角「上传文档」。
2. 拖入或选择 Word / PDF 文件（不超过 20MB，可多选）。
3. 单文件时可修改「文档标题」；多文件时标题自动取文件名。
4. 选择「课程」（可选）和「文档类型」（课件 / 作业 / 论文 / 报告）。
5. 点击「开始上传」，等待状态变为「就绪」。

### 3.2 列表与筛选

- 可在「我的文档 / 回收站」之间切换。
- 支持按课程、文档类型、处理状态、标题关键字筛选。
- 表格显示标题、归属、状态、大小、版本、更新时间与操作。
- 回收站中的文档可以「恢复」。

### 3.3 阅读文档

点击文档行的「预览」进入阅读页：

- 标题、正文、列表、表格、代码块、图片会按结构显示；
- 有页码时会显示分页提示；
- 摘要、要点、问答中的引用可以点击回到原文位置；
- 页面提示正在准备时，智能处理暂时不可用，请稍等。

### 3.4 编辑文档

只有文档的创建者可以编辑。

1. 在预览页点击右上角「编辑」。
2. 每一行是一个内容块，可设置为：一级标题、二级标题、正文、代码块、图片。
3. 点击底部「+ 添加块」可以新增内容块；代码块可选择代码类型，系统会自动识别常见代码行。
4. 图片块点击「上传图片」，支持 PNG / JPEG / GIF / WEBP，上传后可在编辑区预览，也可以替换。
5. 拖动内容块左侧的拖动标记可以调整顺序。
6. 点击「保存为新版本」生成新版本；点击「取消」放弃本次编辑。
7. 点击「导出 Word」可以下载文档的 Word 版本；导出文件暂不包含文档内图片。

### 3.5 智能处理

在文档预览页右侧面板中使用：

- **摘要**：点击「生成摘要」，完成后显示摘要；点击引用可回到原文。
- **要点**：点击「提取要点」，查看文档要点与引用。
- **问答**：输入问题并发送，系统根据文档内容回答并给出引用；文档中没有依据时会提示「证据不足」。
- **润色**：
  1. 在正文中勾选需要润色的正文段；
  2. 点击「润色选中段落」；
  3. 对照原文与润色结果，可直接修改右侧文本；
  4. 点击「采纳」按当前文本生成新版本，或点击「放弃」保留原文；
  5. 本次操作中最近一次采纳可以撤销一次；
  6. 一次最多润色 5000 字，超出请分批处理。

### 3.6 格式检查与修复

1. 打开文档预览，切换到「格式校验」。
2. 点击「开始校验」，等待检查完成。
3. 查看问题清单：问题类型、严重程度、位置、期望值、当前值、是否可修复、修改建议。
4. 勾选可自动修复的问题，点击「一键修复」；修复会生成新版本并自动复查。
5. 不能自动修复的问题，请按修改建议手工调整。
6. 点击问题行的位置，可以跳到文档中对应的段落。
7. 如果当前是编辑后的文本版本，系统会按最近一次的 Word 原件检查版式；PDF 文件暂不支持版式检查。

### 3.7 批注、共享与版本

**批注**

1. 在文档预览页切换到「批注」。
2. 在正文中点击标题、正文段或代码块，或从下拉框选择要批注的块。
3. 输入批注内容，点击「添加批注」。
4. 自己可以删除自己的批注；文档创建者可以标记解决或重新打开。

**共享**

- 在「我的文档」中点击文档行的「共享」，可以生成只读链接或邀请协作者。
- 只读链接可以设置有效期，打开后无需登录即可阅读，不能编辑。
- 被邀请的协作者可以在自己的「我的文档」中看到「协同」文档，并进行批注、问答和格式检查。

**版本**

- 点击文档行的「版本」查看历史版本。
- 可以对比版本或恢复历史版本；恢复会生成新版本，历史版本不会被删除。

## 4 课程与作业

### 4.1 查看作业

- 进入「课程与作业」，查看「我的作业」。
- 列表显示课程、作业名、模板、要求、截止时间、提交状态与格式检查结论。
- 可按状态和课程筛选。
- 作业指定模板时，点击「按模板新建」可以按该模板创建文档。

### 4.2 准备提交文档

可以通过以下方式准备：

1. **按模板新建**：在「格式与模板」中选择教师发布的模板，填写标题后创建，系统会按模板生成文档结构。
2. **基于附件编辑**：在作业提交弹窗中，若教师提供了附件，可点击「基于附件编辑」，系统会把附件复制成你的一份可编辑文档。
3. **上传自己的文档**：在「我的文档」中上传已完成的 Word / PDF，等待状态变为「就绪」。

### 4.3 提交作业

1. 在「我的作业」中找到待提交作业，点击「提交」。
2. 如作业带附件，可在弹窗上方查看作业附件，选择「下载」或「基于附件编辑」。
3. 在「选择提交文档」中选择本人、已就绪、属于该课程的文档。
4. 点击「确认提交」。
5. 超过截止时间但教师允许迟交时，会提示「第 N 次提交成功，已记为迟交」。
6. 提交后状态变为「已提交」。

### 4.4 查看反馈

- 教师批改后，作业状态变为「已批改」，并显示分数。
- 点击「查看反馈」可以查看得分和教师评语。
- 教师评语为选填，可能只有分数没有评语。
- 同一作业可以多次提交，以最新一次提交为准。

### 4.5 导出与下载

1. 进入「课程与作业」→「导出文档」。
2. 选择文档和目标格式（PDF / DOCX），点击「开始导出」。
3. 在「下载中心」查看进度：排队、生成中、可下载、失败、已取消。
4. 成功后点击「下载」；失败可以重新导出。

## 5 消息与个人中心

### 5.1 消息通知

- 查看作业提醒、批改反馈、格式异常等消息。
- 可以按「全部 / 未读 / 已读」和消息类型筛选。
- 可以标记已读/未读，或一键全部已读。
- 带「前往处理」的消息可以跳转到相关作业或文档。

### 5.2 个人中心

- **个人资料**：查看姓名、账号、角色、组织等信息；实名信息由学校统一提供，只读。
- **账号与安全**：修改登录密码；查看双因素认证、新设备登录提醒、通知偏好、当前会话和登录记录。
- 修改密码后需要重新登录。

## 6 常见提示与处理

| 提示/现象 | 处理 |
| --- | --- |
| 上传文档失败 | 检查文件是否超过 20MB、格式是否为 Word / PDF、网络是否正常；仍失败联系教师或管理员 |
| 文档一直显示「解析中」 | 稍等 1–2 分钟；仍失败可点「重新解析」或重新上传 |
| 格式校验按钮不可用 | 确认文档已经是「就绪」状态，并确认自己有权使用格式检查 |
| 格式检查提示 PDF 不支持 | PDF 暂不支持版式检查，请上传 Word 原件或按模板自查 |
| 一键修复不可用 | 只有 Word 原件版本支持一键修复；文本编辑版本或不可自动修复的问题请手工处理 |
| 智能处理不可用 | 文档可能还在准备中；稍等后刷新页面 |
| 问答提示「证据不足」 | 文档中没有相关内容，换一种问法或确认文档内容完整 |
| 提交提示「不是课程成员」 | 联系教师重新导入课程名单 |
| 提交提示「已截止且不允许迟交」 | 联系教师调整截止时间或允许迟交 |
| 图片上传失败 | 检查图片格式（PNG / JPEG / GIF / WEBP）和大小（不超过 10MB） |
| 共享页图片不显示 | 确认链接未过期；图片必须是在该文档中上传的 |
| 看不到某些页签 | 协作者只保留批注、问答、格式检查；这是权限设计 |

## 7 常见问题

| 问题 | 回答 |
| --- | --- |
| 为什么上传后不能马上提交？ | 文档需要先处理到「就绪」状态；建议先做格式检查再提交 |
| 为什么格式检查按 Word 原件？ | 文本编辑后的版本不包含原始版式；系统会用最近一次的 Word 原件检查，避免误判 |
| 一键修复会覆盖原文件吗？ | 不会。修复会生成新的版本，历史版本仍然保留 |
| 共享链接需要登录吗？ | 不需要。链接为只读，可设置有效期，也可以撤销 |
| 协作者能编辑我的文档吗？ | 当前协作者默认只能批注、问答和格式检查；编辑和导出只有文档创建者可用 |
| 为什么批改后不能修改？ | 已批改的提交是只读的，避免覆盖教师评分和反馈 |
| 支持在手机上使用吗？ | 本期仅支持桌面浏览器 |
| 代码块可以选择哪些类型？ | 页面提供代码类型选择，系统会自动识别常见代码行；具体选项以页面显示为准 |

## 8 使用限制与支持

### 8.1 使用限制

- 仅支持桌面浏览器，暂不支持手机、平板；
- 文档上传、图片上传需要网络正常；
- 智能处理、格式检查等能力以页面实际可用状态为准；
- 共享链接为只读，协作者默认只能批注、问答和格式检查。

### 8.2 获取帮助

1. 先查阅本手册第 6、7 节；
2. 记录页面提示与操作时间；
3. 联系课程教师；
4. 仍无法解决时，联系学校系统管理员。
