# 配置说明

> - 适用读者：系统管理员、实施人员
> - 配置文件：`EduDocAssistant/deploy/.env`
> - 模板文件：`EduDocAssistant/deploy/.env.example`

本文件说明部署后需要维护的配置项。首次安装步骤见 [安装.md](安装.md)，启动与停止命令见 [启动.md](启动.md)。

---

## 1 配置文件

进入部署目录：

```bash
cd EduDocAssistant/deploy
```

首次部署：

```bash
cp .env.example .env
```

修改 `.env` 后，执行以下命令使配置生效：

```bash
docker compose --env-file .env up -d
```

> `.env` 含敏感信息，不要提交到版本库；仓库已忽略该文件。

---

## 2 基础配置

| 变量 | 默认值 | 说明 |
| --- | --- | --- |
| `EDUDOC_WEB_PORT` | `8088` | Web 对外端口；被占用时修改 |
| `EDUDOC_ORACLE_PWD` | `EdudocOracle2026` | 数据库管理员密码；首次启动后不要随意修改 |
| `EDUDOC_DB_USERNAME` | `user_cidas` | 业务数据库账号 |
| `EDUDOC_DB_PASSWORD` | `cidas123` | 业务数据库密码 |
| `EDUDOC_JWT_SECRET` | 空 | 登录令牌签名密钥；留空时启动脚本自动生成 |
| `EDUDOC_AI_INTERNAL_TOKEN` | 空 | 业务服务与智能处理服务的共享令牌；留空时自动生成 |
| `EDUDOC_INSTALL_CONVERT` | `true` | 是否安装格式转换组件；设为 `false` 可加快首次构建 |

---

## 3 智能处理配置

| 变量 | 默认值 | 说明 |
| --- | --- | --- |
| `SILICONFLOW_API_KEY` | 空 | 模型服务密钥；不填则摘要、要点、问答、润色不可用 |
| `SILICONFLOW_BASE_URL` | `https://api.siliconflow.cn/v1` | 模型服务地址 |
| `EDUDOC_LLM_MODEL` | `deepseek-ai/DeepSeek-V3` | 摘要/要点/润色使用的模型 |
| `EDUDOC_ANSWER_MODEL` | `Qwen/Qwen2.5-7B-Instruct` | 问答使用的模型 |
| `EDUDOC_EMBEDDING_MODEL` | `BAAI/bge-m3` | 向量化模型 |
| `EDUDOC_RERANK_MODEL` | `BAAI/bge-reranker-v2-m3` | 检索重排模型 |

> 模型名称以实际服务账户可用的模型为准；修改后重启 `ai-service` 与 `backend`。

## 4 对象存储配置

| 变量 | 说明 |
| --- | --- |
| `EDUDOC_OSS_ENDPOINT` | 对象存储访问地址 |
| `EDUDOC_OSS_REGION` | 地域 |
| `EDUDOC_OSS_BUCKET` | Bucket 名称 |
| `EDUDOC_OSS_ACCESS_KEY_ID` | 访问密钥 ID |
| `EDUDOC_OSS_ACCESS_KEY_SECRET` | 访问密钥 Secret |
| `EDUDOC_OSS_ROLE_ARN` | 浏览器直传使用的角色 |
| `EDUDOC_OSS_STS_ENDPOINT` | 临时凭据服务地址 |

未配置对象存储时，系统可以启动，但上传文档、作业附件、文档图片会提示服务不可用。

### 4.1 Bucket 跨域配置

浏览器上传需要给 Bucket 配置跨域规则：

- 来源：`http://<服务器地址>:8088`（或实际域名/端口）
- 方法：`GET, PUT, POST, HEAD`
- 请求头：`*`
- 暴露头：`ETag`

否则浏览器会因跨域失败而无法上传。

## 5 端口与数据卷

| 项目 | 值 |
| --- | --- |
| Web 入口 | `http://<服务器>:8088` |
| 业务服务 | `8080`（仅容器内部） |
| 智能处理服务 | `8000`（仅容器内部） |
| 数据库 | `1521`（仅容器内部） |
| 缓存/任务队列 | `6379`（仅容器内部） |
| 数据库数据卷 | `edudoc_oracle_data` |
| 缓存数据卷 | `edudoc_redis_data` |

---

## 6 生产环境建议

- 对外部署时在 Web 前增加 HTTPS 反向代理；
- 不要将 `.env` 提交到版本库；
- 条件允许时使用密钥管理服务保存访问密钥与模型密钥；
- 定期备份 `edudoc_oracle_data` 数据卷；
- 修改数据库管理员密码前先确认数据卷状态，避免旧密码与新配置不一致。
