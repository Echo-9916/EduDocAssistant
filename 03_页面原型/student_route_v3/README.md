# 学生路线 v3

学生端 27 屏静态原型，基于 `STUDENT_DESIGN.md`、现有 SVG 导出稿和需求规格重新整理。教师端与合并后的运维端位于 `staff_routes_v3/`。

## 打开方式

在 `student_route_v3` 目录启动静态服务器：

```powershell
$env:PORT=4173
node .\capture-server.mjs
```

打开：

- 交互原型：`http://127.0.0.1:4173/`
- 27 屏总览：`http://127.0.0.1:4173/board.html`

也可以直接打开 `index.html`，但本地服务器方式更接近最终演示环境。

## 交互边界

- 27 屏作为彼此独立的静态画面保留，页面之间不设置切换、翻页、热点或原型反应。
- 左侧 8 项学生导航仅用于展示信息架构，不再触发页面跳转。
- 通过 `#页面id` 可在刷新时直达指定画面，仅供审阅、截图与定位使用。
- 页面内保留筛选、勾选、开关、表单状态和模板弹窗等局部交互。
- 导出和提交会显示成功状态；转换会显示任务已开始状态。
- 文档支持名称搜索、课程/状态筛选、全选、批量操作和结果为空状态。
- 上传文件可以单独移除或重新选择；无文件时上传按钮不可用。
- 要点、自动修复项和模板要求支持勾选、展开和动态按钮状态。
- 下载、作业和消息支持分类筛选；消息可在当前页标为已读。
- 共享范围、个人资料编辑、转换进度和主要开关均有即时状态反馈。
- 文本摘要提供摘要要求、长度和关注重点设置，并明确生成、定位、复制和导出操作。
- 文档问答与拒答页统一提供“清除对话”和“导出对话”。
- 格式转换提供 6 种转换方式、左侧抽屉折叠和标准 A4 预览滚动。
