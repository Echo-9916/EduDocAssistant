# 桌面端页面原型说明

面向师生的校园智能文档辅助系统（EduDocAssistant）· 桌面 Web 端原型第 1 版

## 一、如何查看

- 直接双击 `index.html` 用浏览器打开即可（无需联网、无需构建）；
- 左侧是页面清单，点击任意一项切换页面；也可用键盘 `←` `→` 前后翻页；
- 顶部工具栏可切换「适应窗口 / 100%」缩放；
- 顶部工具栏右侧提供评审用的「框选批注 / 导出批注 / 清空」。

原型按 1440×900 的桌面画布设计，内容按固定宽度排版，便于与前端实现尺寸对齐。

> 页面截图已导出到 `预览图` 目录，并同步插入《需求规格说明书》第 5 章各功能点的【页面效果】。

## 三、框选批注（评审用）

1. 点击顶部 **框选批注**（或按 `A` 键）进入批注模式，光标变为十字；
2. 在页面上拖动框选要修改的区域，松开后在弹窗中填写意见（`Enter` 保存，`Esc` 取消）；
3. 批注以编号方框显示在页面上，左侧清单列出全部批注，可逐条删除；
4. 点击 **导出批注** 会下载 `原型批注.md` 并同时复制到剪贴板，把文件或文本发回即可逐条修改；
5. 批注保存在浏览器本地（localStorage），刷新不丢失；**清空** 可全部删除。

每条批注记录：页面编号与页面名、选区在设计稿中的坐标与尺寸、选区对应的元素路径与文本、批注内容。

## 四、设计令牌

后续在 Figma 或前端实现中可直接复用下列取值（与 `styles.css` 中的变量一致）。

| 类别 | 取值 |
| --- | --- |
| 品牌主色 | 深蓝 `#1F3864`（左侧导航、标题强调） |
| 主操作色 | `#2563EB`（主要按钮、链接、进度） |
| 页面底色 / 卡片 | `#F5F7FA` / `#FFFFFF` |
| 描边 | `#E3E8EF`（常规）、`#CBD5E1`（表单控件） |
| 文字 | 主 `#1F2937`、次 `#475569`、弱 `#64748B` |
| 状态色 | 成功 `#16A34A`、提醒 `#B45309`、错误 `#DC2626`、信息 `#2563EB` |
| 字体 | 系统中文 UI 字体：Segoe UI / 微软雅黑 / PingFang SC；正文 14px，辅助 12px |
| 圆角 | 卡片 8px、控件 6px、标签胶囊 999px |
| 间距 | 8px 基准，卡片内边距 16px，区块间距 14px |
| 阴影 | `0 1px 2px rgba(16,24,40,.06), 0 1px 3px rgba(16,24,40,.08)` |

页面统一结构：左侧 208px 导航（深蓝）＋ 顶部 56px 工具栏＋内容区（内边距 20×24）。

## 五、本期范围与后续迭代

本期只覆盖桌面端，与《需求规格说明书》6.1 与 9.3 的口径一致：设计基准为 1440×900，本期不产出移动端页面，也不承诺移动端的浏览效果。移动端适配列入后续迭代，届时按下列顺序推进：

1. **断点**：桌面 ≥1280px，平板 768–1279px，移动 <768px。
2. **导航**：左侧导航在移动端收起为底部标签栏（我的文档 / 智能处理 / 模板 / 我的），管理类页面收进“更多”。
3. **列表与表格**：我的文档、提交名单、操作日志由表格改为卡片流，每张卡片保留标题、状态标签与主操作；筛选条件收进抽屉。
4. **文档预览**：章节导航改为顶部下拉或抽屉，正文单栏滚动，处理入口改为底部固定操作条。
5. **智能处理**：摘要与要点改为单列卡片；问答改为全屏对话（输入框固定在底部）；润色的左右对照改为上下或标签切换。
6. **对话框**：共享设置、导出对话框在移动端改为全屏抽屉，底部固定“取消 / 保存”。
7. **格式校验**：问题清单以卡片呈现，每条问题保留“定位 / 一键修复”两个主操作。
8. **协作与版本**：协作者头像与版本记录改为顶部状态条＋底部抽屉。
9. **触控规格**：可点击区域不小于 44×44px，正文不小于 16px 以免移动浏览器自动缩放。
