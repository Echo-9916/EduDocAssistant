# 接口契约速查

> 精简自《详细设计说明书》§2.3/§5.1/§5.3/§4.4，供前后端实现对齐。代码落地见 `common/api/`。

## 1 统一响应 envelope

所有 REST 接口返回：

```json
{
  "code": 200,
  "message": "success",
  "data": {},
  "traceId": "2f6b...",
  "timestamp": "2026-10-31T04:00:00Z"
}
```

- `code`：业务码，成功固定 `200`；HTTP 状态由接口语义决定（查询 200、创建 201、删除 204）。
- `message`：成功 `success`；失败为错误码默认提示或自定义提示。
- `data`：业务数据，失败为 `null`。
- `traceId`：从请求头 `X-Trace-Id` 透传，缺省由服务端生成并回写响应头。
- `timestamp`：UTC ISO-8601（`Instant`）。

## 2 错误码

| 业务 code | HTTP | 含义 |
| --- | --- | --- |
| 200 | 200/201/204 | 成功 |
| 40001 | 400 | 参数校验失败 |
| 40101 | 401 | 未登录或令牌过期 |
| 40102 | 401 | 令牌已撤销 |
| 40301 | 403 | 角色权限不足 |
| 40302 | 403 | 文档 ACL 拒绝 |
| 40303 | 403 | 共享链接过期或撤销 |
| 40401 | 404 | 资源不存在或不可见 |
| 40501 | 405 | 请求方法不允许（1103 审查整改新增，已同步《详细设计说明书》§5.1） |
| 40901 | 409 | 版本或并发冲突 |
| 40902 | 409 | 重复提交或幂等键冲突 |
| 41301 | 413 | 文件超过 20MB |
| 41501 | 415 | 文件类型不支持 |
| 42201 | 422 | 文档结构无法解析 |
| 42202 | 422 | 格式校验存在阻断问题 |
| 42901 | 429 | 请求或任务并发超限 |
| 50001 | 500 | 服务器内部错误 |
| 50201 | 502 | 模型服务失败 |
| 50301 | 503 | OSS 或数据库暂时不可用 |
| 50401 | 504 | 处理超时 |

## 3 请求约定

- 路径前缀 `/api/v1`；身份令牌放 `Authorization: Bearer <token>`。
- 所有请求透传 `X-Trace-Id`（前端生成 UUID）。
- 分页：`page`（从 1 起）、`pageSize`、`sort`；响应用 `PageResult{items,total,page,pageSize}`。
- 幂等写操作（创建上传会话、完成上传、创建 AI 任务、提交作业、创建导出任务）必须带 `Idempotency-Key`。
- 前端按 §2 错误码做客户端处理：40101→跳登录并保留回跳；40301/40302→无权限态；5xx→展示 traceId。

## 4 公共类型

- `ApiResponse<T>`：见 §1。
- `PageResult<T>`：`{items: T[], total: long, page: int, pageSize: int}`。
- `UserPrincipal`：`{userId, roles, courseScope}`（请求上下文，认证任务 F-03 落地）。

## 5 文档域接口（02 切片落地，含 B-02 要求回填的契约外辅助接口）

| Method / Path | 权限点 | Idempotency-Key | 成功返回 | 说明 |
| --- | --- | --- | --- | --- |
| `GET /api/v1/courses` | 认证即可，无权限点 | 否 | 200 `[{id,courseCode,courseName,termCode,memberRole}]` | **契约外辅助接口**（B-02 回填）：上传表单与列表筛选的课程数据源 |
| `POST /api/v1/documents/upload-sessions` | DOCUMENT_CREATE | 是 | 201 `{sessionId,objectKey,bucket,region,endpoint,sts{…}}` | 校验 20MB/类型双验/课程成员；STS 900s，inline policy 收窄到单 objectKey；`region` 为阿里云地域名、`endpoint` 为 OSS 端点，**直传用 endpoint** |
| `POST /api/v1/documents/upload-sessions/{id}/complete` | DOCUMENT_CREATE | 是 | 201 `{documentId,versionId}` | 服务端实算 SHA-256 比对；单事务五写+审计；COMPLETED 会话换 key 重放返回原结果 |
| `GET /api/v1/documents` | DOCUMENT_READ | 否 | 200 `PageResult<DocumentSummary>` | 强制 owner=当前用户；筛选 courseId/type/status/keyword；默认排除 DELETED，`status=DELETED` 查回收站 |
| `GET /api/v1/documents/{id}` | DOCUMENT_READ | 否 | 200 `DocumentDetail` | 非 owner → 40401（不泄露存在性） |
| `DELETE /api/v1/documents/{id}` | DOCUMENT_DELETE | 是 | 204 | 软删，`purge_at=+30d`，不动 OSS |
| `POST /api/v1/documents/{id}/restore` | DOCUMENT_DELETE | 是 | 204 | 仅 DELETED；恢复态按分块有无推 READY/FAILED；撞同名 → 40901 |
| `POST /api/v1/documents/{id}/parse` | DOCUMENT_EDIT | 是 | 200 `{taskId}` | 仅 READY/FAILED；body `{versionId?}`（仅允许当前版本）；taskId=outbox eventId hex |

- 错误码补充：会话过期/不存在 40401 · 非本人会话 40301 · 大小/哈希不符 40901 · 同名（含回收站）40901 · 未直传 complete 40901。
- 权限映射说明：restore/parse 无专属权限点，分别复用 DOCUMENT_DELETE / DOCUMENT_EDIT（任务文档 B-08 记录）。
