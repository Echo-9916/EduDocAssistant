# 启动与停止

> - 适用读者：系统管理员、实施人员
> - 部署目录：`EduDocAssistant/deploy`

首次安装与配置见 [安装.md](安装.md) 与 [配置.md](配置.md)。

---

## 1 一键启动

Windows PowerShell：

```powershell
cd EduDocAssistant\deploy
.\start.ps1
```

Linux / macOS / Git Bash：

```bash
cd EduDocAssistant/deploy
chmod +x start.sh
./start.sh
```

脚本会：

1. 检查 Docker 与 Compose；
2. 确保 `.env` 存在；
3. 为空时自动生成登录密钥与共享令牌；
4. 构建镜像并启动全部服务；
5. 等待 Web 就绪，打印访问地址与演示账号。

首次启动需要初始化数据库，通常 5–10 分钟；后续启动约 1 分钟。

---

## 2 手动启动

在 `EduDocAssistant/deploy` 目录执行：

```bash
docker compose --env-file .env up -d --build
```

只启动，不重新构建：

```bash
docker compose --env-file .env up -d
```

只重建某个服务：

```bash
docker compose --env-file .env build backend
docker compose --env-file .env up -d backend
```

## 3 查看状态

```bash
docker compose --env-file .env ps
```

正常状态：

| 服务 | 预期状态 |
| --- | --- |
| `edudoc-oracle` | `Up (healthy)` |
| `edudoc-redis` | `Up (healthy)` |
| `edudoc-ai` | `Up (healthy)` |
| `edudoc-backend` | `Up (healthy)` |
| `edudoc-web` | `Up (healthy)`，映射 `8088` |
| `edudoc-db-init` | `Exited (0)`，一次性初始化完成 |

> `db-init` 显示 `Exited (0)` 是正常的；它不是常驻服务。

## 4 验证

浏览器打开：

```text
http://<服务器地址>:8088
```

演示账号：

| 角色 | 账号 | 密码 |
| --- | --- | --- |
| 教师 | `teacher` | `Cidas@123` |
| 学生 | `student` | `Cidas@123` |
| 运维 | `ops` | `Cidas@123` |

也可以直接验证登录接口：

```bash
curl -s -X POST http://localhost:8088/api/v1/auth/login \
  -H 'Content-Type: application/json' \
  -d '{"username":"teacher","password":"Cidas@123"}'
```

返回 `"code":200` 表示 Web、业务服务、数据库链路正常。

## 6 停止、重启与重置

### 停止（保留数据）

```bash
./stop.sh          # Windows: .\stop.ps1
```

等价于：

```bash
docker compose --env-file .env down
```

### 重启

```bash
docker compose --env-file .env restart
```

### 重新构建应用

```bash
docker compose --env-file .env up -d --build backend web ai-service
```

### 清空数据并重建

```bash
docker compose --env-file .env down -v
```

> 该命令会删除数据库与缓存数据，下次启动会重新初始化；请确认不再需要现有数据。

---

## 7 开机自动启动

- `oracle / redis / ai-service / backend / web` 配置了自动重启；
- `db-init` 是一次性初始化容器，不参与自动重启；
- 机器重启后，建议登录后执行一次 `./start.sh` 或 `docker compose --env-file .env up -d`，并确认 `ps` 全部 healthy。
