# 演示操作手册（教师 / 学生从 0 到 1，2026-11-22 更新）

> 本手册从「教师新建课程」开始，完整走到「学生提交作业 → 教师批改 → 学生看到分数与消息」。
> 所有按钮、菜单、提示均取自当前前端源码；页面文案找不到原文的标「待确认」。
> 适用环境：`oracle-dev` / `redis-dev`、backend `localhost:8080`、web `localhost:5173`、ai-service `localhost:8000`。

## 一、教师端：新建课程并发布作业

### 1. 登录教师端

| 步骤 | 操作 | 期望结果 |
| --- | --- | --- |
| 1 | 打开 `http://localhost:5173/login`，输入 `teacher` / `Cidas@123`，点「登录」 | 进入「身份认证成功」 |
| 2 | 点「进入工作台」 | 落在「教学工作台」 |
| 3 | 左侧点「课程与作业」 | 默认打开「课程管理」Tab |

### 2. 新建课程

| 步骤 | 位置 / 原文 | 输入 / 结果 |
| --- | --- | --- |
| 1 | 课程管理右上角「新建课程」 | 弹窗标题「新建课程」 |
| 2 | 「课程名称」 | `演示课程-文档协作` |
| 3 | 「课程代码」 | `DEMO-1115`（同一学期内唯一；重复会报 40902，换一个代码即可） |
| 4 | 「学期」 | 选 `2026-2027 秋` |
| 5 | 「默认文档权限」 | 保持默认「可评论」；该字段后端创建接口暂不接收 |
| 6 | 点「创建课程」 | 提示 `课程《演示课程-文档协作》已创建，可通过「成员导入」添加学生`；课程列表出现一行，状态「进行中」，操作列有「成员导入」 |

> 教师创建课程时后端会自动把创建者登记为课程成员，所以教师本人立刻能看到这门课；学生还需要下一步导入。
> 课程列表「学生数」下方有「查看所有学生」，点击后弹出「全部学生」弹窗（学号 / 姓名 / 课程组，10 条/页），不再行内展开；课程表格已去掉「关联模板」列，课程组数所在列名为「课程组」。

### 3. 把学生加入课程

| 步骤 | 位置 / 原文 | 输入 / 结果 |
| --- | --- | --- |
| 1 | 新课程行右侧「成员导入」 | 弹窗标题「课程成员导入 · 演示课程-文档协作」 |
| 2 | 「拖拽课程成员名单 CSV 到此处」 | 上传 `docs/demo/演示课程成员.csv`（或自己按表头 `学号,姓名,课程组` 准备） |
| 3 | 查看「导入预览」 | 显示解析出的 4 行：`student 张同学 演示组`、`2023001 陈同学 课程组 3`、`2023002 刘同学 课程组 3`、`2023003 王同学 课程组 5` |
| 4 | 点「确认导入」 | 提示 `导入完成：新建 N · 激活 N · 冲突 N · 失败 N`；`student` 被写入课程成员 |
| 5 | 点「关闭」 | 回到课程列表 |

- 导入结果里 `新建` 指已有账号被加入课程，`激活` 指名单里没有账号时新建的未激活账号；以弹窗数字为准。
- 这一步完成后，学生端刷新「课程与作业」就能看到新课程。

### 4. 发布作业（含指定模板）

> 发布前先在「课程模板」为该课程创建并发布一个模板（否则「指定模板」下拉为空）：教师左侧「课程模板」→「新建模板」选本课程 → 编辑模板 → 上传 `docs/demo/实验五_泛型类和泛型接口_模板.docx` 解析规则（或点「添加规则」逐条设置）→「确认保存为新版本」→「发布确认」。没有 .docx 源文件时，规则版本也可直接发布。

| 步骤 | 位置 / 原文 | 输入 / 结果 |
| --- | --- | --- |
| 1 | 课程与作业 → Tab「作业与提交统计」 | 打开作业列表 |
| 2 | 右上「发布作业」 | 弹窗标题「发布作业」，左侧表单、右侧「学生端预览」 |
| 3 | 「所属课程」 | 选 `演示课程-文档协作（2026-2027 秋）` |
| 4 | 「指定模板」 | 选该课程已发布的模板，例如 `Web开发技术课程设计报告模板（v1）`；学生端会看到这个模板，并可去「格式与模板」按它新建/编辑文档 |
| 5 | 「作业标题」 | `演示作业-1115` |
| 6 | 「作业要求」 | `按课程模板提交设计报告，含需求分析、系统设计、实现与测试、格式规范、结论与思考。` |
| 7 | 「截止时间」 | 选演示当天之后的时间（不要选过去，否则学生端显示逾期） |
| 8 | 「提交格式」 | `DOCX / PDF` |
| 9 | 「允许迟交」 | 保持开 |
| 10 | 「要求格式校验」 | 保持关（不阻断提交；提交时后端会关联学生最近一次已完成的格式校验） |
| 11 | 「作业附件」（可选） | 点「上传 .docx 附件」选择参考文件，可上传多个；仅支持 `.docx`（与课程模板格式一致），单文件 ≤20MB。上传成功后以标签显示，可点 × 移除 |
| 12 | 评分标准 | 保持 5 项各 20 分（总分 100） |
| 13 | 点「确认发布」 | 提示 `作业《演示作业-1115》已发布，学生端「课程与作业」同步可见`；列表新增一行，状态「已发布」，模板列显示所选模板 |

- 作业行右侧「提醒未提交学生」：先弹出未提交名单，点「发布提醒」会真正写入站内消息；同一学生同一作业同一天只提醒一次。
- 作业可同时携带**模板版本**与 `.docx` 附件；附件格式要求与课程模板一致。学生端在提交/详情弹窗里可下载附件，或点「基于附件编辑」把附件复制为本人可编辑文档（自动绑定作业模板），再走「保存为新版本 → 提交」。

## 二、学生端：从登录到提交

### 5. 学生登录并看到新课程/作业

| 步骤 | 操作 | 期望结果 |
| --- | --- | --- |
| 1 | 隐身窗口打开 `http://localhost:5173/login`，输入 `student` / `Cidas@123`，点「登录」→「进入工作台」 | 落在学生工作台 |
| 2 | 左侧「课程与作业」 | 「我的作业」表出现 `演示作业-1115`，课程列为 `演示课程-文档协作`，状态「待提交」；「模板」列显示教师指定的模板名与版本 |
| 3 | 点作业行的「按模板新建」 | 跳到「格式与模板」，自动/手动选同一模板，可「按模板新建文档」 |
| 4 | 若没看到 | 按 `F5` 刷新；仍没有则回到教师端确认成员导入结果 |

#### 5.1 按作业模板新建并编辑（推荐主线）

| 步骤 | 位置 / 原文 | 输入 / 结果 |
| --- | --- | --- |
| 1 | 学生「格式与模板」 | 模板下拉选作业指定的模板 |
| 2 | 「按模板新建文档」 | 填标题，点「创建」；提示 `已按模板创建文档，正在解析`，跳转到文档预览 |
| 3 | 文档预览 → 「编辑」 | 进入块编辑：一级/二级标题、正文、代码块、图片；代码块可选 Java / C/C++ / Python / SQL 并高亮 |
| 4 | 代码段自动识别 | 从 Word/正文识别出的连续代码行会自动合并为「代码块」并默认 Java（如 `public interface …`、`T area();`、`}`） |
| 5 | 左侧 `⠿` | 拖动调整块顺序 |
| 6 | 底部「+ 添加块」→「图片」 | 新增图片块后点「上传图片」，支持 PNG/JPEG/GIF/WEBP（≤10MB）；上传后编辑区立即预览，可「替换图片」 |
| 7 | 「保存为新版本」 | 生成新的 `EDIT` 版本；预览按标题/段落/代码块/图片结构化展示 |
| 8 | 需要 Word 时点「导出 Word」 | 按模板样式导出 `.docx`（语义结构版，不保证页面版式与原件完全一致；内联图片暂不写入导出文件） |

- 生成的文档归学生本人所有，可继续编辑并用于提交；这满足「查阅作业携带的模板 → 按模板进一步编辑」。
- 如果现场不想等待应用内生成，可直接上传 `docs/demo/实验五_泛型类和泛型接口_按模板新建示例.docx` 作为“按模板新建后的骨架”演示；主线仍建议走应用内「按模板新建」。
- 作业可携带 `.docx` 附件：提交/详情弹窗里可「下载」，或点「基于附件编辑」复制为本人可编辑文档（自动绑定作业模板）。
- 图片块只支持文档内预览；导出 Word 时暂不嵌入图片。

### 6. 学生上传一份「就绪」文档

| 步骤 | 位置 / 原文 | 输入 / 结果 |
| --- | --- | --- |
| 1 | 左侧「我的文档」 | 打开文档列表 |
| 2 | 右上「上传文档」 | 弹窗标题「上传文档」 |
| 3 | 拖入或选择 `.docx` / `.doc` / `.pdf` | 选 `docs/demo/实验五_泛型类和泛型接口_学生报告.docx`；单文件不超过 20MB |
| 4 | 「文档标题」 | `实验五 泛型类和泛型接口_张同学` |
| 5 | 「选择课程（可选）」 | 选「演示课程-文档协作」 |
| 6 | 「文档类型」 | 选「作业」 |
| 7 | 点「开始上传」 | 弹窗关闭，列表新增一行 |
| 8 | 等待状态标签 | 「解析中」→「就绪」；只有「就绪」才能提交 |

- 上传依赖 OSS 配置；若失败，先检查后端 OSS 环境变量与 Bucket CORS，不要在现场反复重试。
- 如果已经按 5.1 用模板新建并编辑过，可跳过上传，直接用那份「就绪」文档提交；也可用种子里已有的 READY 文档。
- 我的文档列表表头为：标题、归属、状态、大小、版本、更新时间、操作；教师端多一列「课程」；「类型」列已移除。协作文档的归属标签显示「协同」。
- **想看到真实格式校验结果**：提交前在「我的文档」打开该文档预览 → Tab「格式校验」→「开始校验」，等横幅显示「校验通过」。提交时后端会自动关联该版本最近一次 `PASSED/FAILED` 校验；没跑过则教师侧显示「未校验」。
- 想演示「发现问题」时，上传 `docs/demo/实验五_泛型类和泛型接口_格式问题示例.docx` 并校验；该文件故意使用错误字体/字号/页边距，不要用于提交主线。
- 若当前版本是块编辑/润色生成的文本版本，校验会**回退到最近一次 `.docx` 原件**的版式做比对（不会因文本重排而“洗白”格式问题），问题示例仍会判为不通过。

### 7. 学生提交作业

| 步骤 | 位置 / 原文 | 输入 / 结果 |
| --- | --- | --- |
| 1 | 「课程与作业」→ `演示作业-1115` 行 | 点「提交」 |
| 2 | 弹窗「提交作业 · 演示作业-1115」 | 若作业带附件，弹窗上方「作业附件」可「下载」或「基于附件编辑」；「选择提交文档」选刚上传或按模板新建并编辑好的「就绪」文档 |
| 3 | 点「确认提交」 | 提示 `第 1 次提交成功`；该行状态变「已提交」，按钮变「查看提交」 |

- 如果之前已经提交过，提示会变成第 N 次提交；建议演示前跑一次复位。
- 提交只接受本人、READY、属于该课程的文档；非课程成员会 40301。

## 三、教师批改

### 8. 教师查看提交并打分

| 步骤 | 位置 / 原文 | 输入 / 结果 |
| --- | --- | --- |
| 1 | 教师窗口按 `F5`，课程与作业 → Tab「批改与反馈」 | 左侧「提交列表」出现学生「张同学」 |
| 2 | 点击该提交行 | 右侧「评分与反馈」载入文档与 5 项评分输入框 |
| 3 | 5 项各填 `16` | 评语可填可不填（选填，例如 `结构完整，补充参考文献卷期号。`） |
| 4 | 点「保存并反馈」 | 提示 `评分已保存：总分 80（服务端按评分标准计算）`；左侧该行状态变「已批改 80 分」；反馈留空也能正常提交 |

- 提交列表上方支持按「课程 / 学号或姓名 / 状态」筛选；点「搜索」或选择下拉即重新请求。
- 已批改的提交是只读的：评分输入框与「保存并反馈」都会禁用，后端也会拒绝重复批改。
- 批改页「格式校验」：学生提交前跑过校验则显示通过/警告/阻塞；没跑过显示「未校验」。
- 分项不能超过该项满分；评分项名称必须与作业 rubric 一致。
- 若左侧没有提交，先确认学生提交成功，再刷新教师页。

| 共享链接 | 学生「我的文档」→ 文档行「共享」→ 选有效期 →「生成只读链接」→「复制链接」 | 可复制 `/s/{token}`；隐身窗口打开为免登录只读页，按结构层渲染标题/正文/列表/表格，并显示文档内图片 |
| 文档内图片 | 文档预览 →「编辑」→ 底部「+ 添加块」→「图片」→「上传图片」 | 支持 PNG/JPEG/GIF/WEBP（≤10MB）；编辑区与只读预览显示图片，保存后进入新版本 |
| 批注 | 文档预览 → Tab「批注」→ 点击正文/标题/代码块或搜索选择 → 输入 →「添加批注」 | 作者可「标记解决」「重新打开」「删除」；owner 可解决/重开但不能删他人批注 |
| 协作者 | 「我的文档」→ 文档行「共享」→ 邀请协作者（可批注）→ 搜索课程教师/学生 →「邀请」 | 被邀请人立即在自己的「我的文档」看到该文档，归属「协同」；可在同一弹窗移除；「协作与版本 → 共享设置」仍可查看和管理协作者 |
| 运维 KPI | 运维端「运维工作台」 | 四张真实卡：用户总数、文档总数、近 7 天高风险、存储占用率；下方风险事件/服务健康/待办审批仍为静态内容 |
| 运维冻结 | 运维端「用户与权限」→「用户目录」→ 学生行「冻结」/「解冻」 | 提示 `已冻结账号 张同学` / `已解冻账号 张同学`；不能操作自己与 OPS |
| 审计 | 运维端「审计与安全」→「操作日志」→「检索」→「事件详情」 | 发布/提交/批改事件出现在时间线，详情含链路与影响面 |

> 共享弹窗已拆为「共享链接（只读）」和「邀请协作者（可批注）」两部分。共享链接不再提供「可批注」选项；历史 COMMENT 链接在列表中显示为「只读（历史）」。
> 邀请协作者只查询文档所属课程的教师/学生，支持姓名/账号搜索和多选；邀请后立即生效，被邀请人可在自己的「我的文档」看到文档并归属「协同」。文档未关联课程时邀请入口禁用。
> 协作者预览只保留「批注」「问答」「格式校验」；摘要、要点、润色、编辑、导出 Word、版本、共享、删除均不可见。格式校验中的「一键修复」仅 owner 可用。
> 文档预览只保留结构化阅读：标题层级、列表、表格、图片按语义渲染，AI 引用回跳、批注与格式问题定位都在这个视图；AI 的「定位」按块编辑同口径显示一级/二级标题、正文、代码块，不再显示页码。
> 文档 owner 点「编辑」可做块编辑：一级/二级标题、正文、代码块（Java / C/C++ / Python / SQL 高亮）、图片；块左侧 ⠿ 可拖动排序；底部「+ 添加块」下拉含「图片」；保存生成新版本；右上「导出 Word」按模板样式导出 `.docx`（暂不含内联图片）。
> 摘要生成后默认折叠；摘要/要点按与块编辑一致的结构块生成与引用（一个一级标题/正文段/代码块各一块），不再按页或整段 chunk 定位；润色只允许勾选正文块（标题/代码块不可选），采纳后保留原结构，不会把全文退化成正文块；批注按同一套块选择，可在批注页直接点正文/标题/代码块并支持文本筛选。块编辑/润色生成的文本版本也能直接发起格式校验（后端回退到最近一次 `.docx` 原件的版式比对，不会因文本重排而误判通过）。

### 2. 常见问题

| 现象 | 可能原因 | 处理 |
| --- | --- | --- |
| 新建课程提示 40902 | 同一学期课程代码重复 | 换一个课程代码，或复用已有课程 |
| 成员导入按钮是灰的 | 没有选择 CSV，或 CSV 没有解析到有效行 | 上传 `docs/demo/演示课程成员.csv`；确认首行是 `学号,姓名,课程组` |
| 学生端看不到新课程 | 导入未成功；学生页没刷新 | 看导入结果弹窗；学生页 `F5`；查 `edudoc_course_member` |
| 学生提交提示 40301 | 学生不是新课程成员 | 重新导入；确认预览行里有 `student` |
| 弹窗没有可提交文档 | 文档不是本人、不是 READY、不是本课程 | 重新上传并等「就绪」；确认课程选对 |
| 提交提示 409 | 作业已截止且不允许迟交 | 重新发布截止时间在未来的作业，或打开「允许迟交」 |
| 批改保存提示 400 | 分项超过满分、评分项与 rubric 不一致 | 5 项都填 0–20；刷新批改列表重新载入 rubric |
| 学生没有收到消息 | Worker/Redis 未启动；消息页没刷新 | 看后端日志；`docker ps`；等 2–3 秒后 `F5` |
| 摘要一直排队/失败 | ai-service 未启动；文档未就绪 | 打开 `http://127.0.0.1:8000/health`；等文档「就绪」 |
| 问答回「证据不足」 | 种子演示文档只有分块、没有向量 | 对文档重新解析/向量化，或改用真实上传并等待索引完成 |
| 版本「对比」没有内容 | 文档只有一个版本 | 用种子文档《课程设计报告（演示：版本对比）》演示 v1/v2 |
| 共享链接打不开 | 链接过期/撤销；文档已删除 | 重新生成；确认文档不在回收站 |
| 批注「删除」不可见 | 当前登录人不是批注作者 | 只有作者可删；owner 只能解决/重开 |
| 冻结后仍担心旧令牌 | 冻结不撤销令牌，但每次请求会重查账号状态 | 冻结期间旧令牌会被拒；解冻后未过期令牌恢复可用 |
| 作业附件上传失败 | 不是 `.docx`、超过 20MB，或 OSS 未配置 | 换成 `.docx`；检查后端 OSS 环境变量与 Bucket |
| 图片上传失败 | 不是 PNG/JPEG/GIF/WEBP、超过 10MB，或 OSS 未配置 | 换格式/压缩；检查后端 OSS 环境变量 |
| 格式问题示例仍显示「校验通过」 | 后端还是旧代码（未重启） | 重启 backend 后重新发起校验；新逻辑会回退到最近 `.docx` 原件比对 |
| 共享页图片不显示 | 链接过期/撤销，或图片不属于该文档 | 重新生成链接；确认图片是在该文档编辑时上传的 |
