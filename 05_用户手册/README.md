## 2 系统概览与用途

### 2.1 系统能做什么

- **文档管理**：上传、阅读、编辑、保存版本；
- **结构化阅读**：按标题、正文、列表、表格、代码、图片显示文档；
- **智能处理**：摘要、要点、文档问答、文本润色；
- **格式管理**：课程模板、格式检查、问题定位与一键修复；
- **教学作业**：教师发布作业、学生提交、教师批改与反馈；
- **协作共享**：批注、协作者、只读共享链接、版本恢复；
- **运维治理**：用户目录、账号冻结、审计记录、消息与告警。

### 2.2 角色与手册

| 角色 | 主要任务                                    | 手册                                   |
| ---- | ------------------------------------------- | -------------------------------------- |
| 学生 | 阅读/编辑文档、格式检查、提交作业、查看反馈 | [学生用户操作手册](操作/学生.md) |
| 教师 | 课程管理、模板发布、作业发布、批改反馈      | [教师用户操作手册](操作/教师.md) |
| 运维 | 用户与账号、审计记录、消息与告警            | [运维用户操作手册](操作/运维.md) |

## 3 登录与初始化

### 3.1 使用前准备

- 系统由学校统一提供，用户无需安装软件；
- 使用桌面浏览器（Chrome / Edge / Safari）访问学校提供的系统地址；
- 账号与初始密码由学校或教师提供。

### 3.2 登录

1. 打开系统访问地址；
2. 输入账号与密码，点击「登录」；
3. 在「身份认证成功」页点击「进入工作台」；
4. 首次登录后，建议在「个人中心 → 账号与安全」修改初始密码；
5. 使用完毕后，点击右上角头像菜单中的「退出登录」。

> 账号被冻结、未激活或密码错误时无法登录，请联系教师或管理员。

### 3.3 认识界面

- **左侧导航**：按角色显示工作台、我的文档、智能处理、格式与模板、课程模板、协作与版本、课程与作业、消息、个人中心等；
- **顶部**：页面标题、筛选条件与操作按钮；
- **表格**：列表数据与行内操作；
- **右侧面板**：文档阅读页的智能处理面板。

菜单是否可见取决于账号权限；看不到某个菜单时，请联系教师或管理员确认权限。

## 4 通用操作

### 4.1 文件与图片要求

| 类型       | 要求                                                        |
| ---------- | ----------------------------------------------------------- |
| 文档上传   | Word（`.doc` / `.docx`）或 PDF，单个不超过 20MB，可多选 |
| 文档内图片 | PNG / JPEG / GIF / WEBP，单张不超过 10MB                    |
| 课程模板   | Word（`.docx`）                                           |
| 作业附件   | Word（`.docx`），单个不超过 20MB                          |

> 上传失败时，先检查文件格式、大小和网络；仍失败请联系教师或管理员。

### 4.2 状态说明

| 类别      | 标签                                                   |
| --------- | ------------------------------------------------------ |
| 文档      | 上传中、解析中、就绪、解析失败、已提交、已归档、已删除 |
| 作业      | 待提交、已提交、已批改、逾期                           |
| 模板      | 草稿、已发布、已停用                                   |
| 格式检查  | 未校验、通过、警告、阻塞                               |
| 导出/转换 | 排队、生成中、可下载、失败、已取消                     |

### 4.3 消息通知

- 查看作业提醒、批改反馈、格式异常、系统通知等；
- 可按「全部 / 未读 / 已读」和消息类型筛选；
- 可标记已读/未读，或一键全部已读；
- 带「前往处理」的消息可跳转到相关页面。

### 4.4 个人中心

- **个人资料**：查看姓名、账号、角色、组织等信息；实名信息由学校统一提供，只读。
- **账号与安全**：修改登录密码；查看双因素认证、新设备登录提醒、通知偏好、当前会话与登录记录。
- 修改密码后需要重新登录。

### 4.5 退出与重新登录

- 点击右上角头像菜单中的「退出登录」结束当前会话；
- 登录状态过期后，下一次操作会跳转登录页，重新登录即可；
- 页面数据异常时，可先刷新页面；仍异常时退出后重新登录。

## 6 支持信息

### 6.1 获取帮助

1. 先查阅对应角色手册中的「常见提示与处理」「常见问题」；
2. 记录页面提示与操作时间；
3. 学生请联系课程教师；教师请联系学校管理员；
4. 运维问题请联系系统负责人。

### 6.2 常见问题

| 问题                   | 回答                                                         |
| ---------------------- | ------------------------------------------------------------ |
| 看不到某个菜单         | 菜单受账号角色与权限控制；联系教师或管理员确认               |
| 上传后不能马上提交     | 文档需先处理到「就绪」状态；建议先做格式检查                 |
| 格式检查按 Word 原件   | 文本编辑后的版本不含原始版式；系统会用最近一次 Word 原件检查 |
| 一键修复会覆盖原文件吗 | 不会；修复生成新版本，历史版本保留                           |
| 共享链接需要登录吗     | 不需要；链接为只读，可设置有效期并撤销                       |
| 支持手机使用吗         | 本期仅支持桌面浏览器                                         |

各角色的详细问题见对应手册：

- [学生用户操作手册](操作/学生.md)
- [教师用户操作手册](操作/教师.md)
