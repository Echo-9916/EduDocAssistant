# 运维端 v3 设计说明

## 合并原则

教学管理员与系统运维合并为一个运维端，保留教学治理所需的课程、成员和作业统计能力，也保留账号权限、审计安全、存储和系统服务能力。合并后不再保留独立的教学管理员与系统运维入口。

## 信息架构

运维端使用 7 个一级导航：运维工作台、课程治理、用户与权限、审计与安全、存储与资源、消息与告警、个人中心。

## 页面原则

- 工作台统一呈现课程运行、权限待办、高风险事件和系统资源状态。
- 课程治理与教学运行保持只读边界，运维角色不替代教师评分。
- 用户与权限区分身份、角色、课程范围和职责冲突。
- 审计与安全保留事件原因、影响对象、处置结论和完整时间线。
- 存储与资源同时覆盖容量、回收站、服务健康和配置变更。
- 高风险操作要求二次确认，并明确会话、数据和恢复影响。
