# 登录与认证页面设计规范

## 适用范围

- 登录
- 登录 · 密码可见
- 统一身份认证回调
- 找回密码
- 账号受限与权限申请

## 图层结构

```text
页面画板
└─ RevisedVisual / 页面名称
   ├─ 总画布
   ├─ Left
   │  ├─ 打底色
   │  ├─ 品牌标识
   │  │  ├─ 外边框
   │  │  └─ Logo
   │  ├─ 趣味几何
   │  ├─ 政策链接
   │  └─ 彩带装饰（仅登录成功页）
   └─ Right
      ├─ 中线
      └─ 表单
         ├─ 表单外框
         ├─ 页面标题 / 页面说明
         ├─ 语义字段组
         └─ 操作按钮组
```

原型交互热点位于页面画板顶层，统一使用 `Hotspot / 操作名称`。

## Logo 规范

- 所有认证页面共用登录页中的图片 Logo。
- Logo 为 `品牌标识` 组内的独立矩形图层 `Logo`。
- 填充方式为 `IMAGE / FILL`，不使用文字或重绘图形代替。
- 后续替换图片时，只需替换该矩形的图片填充，不需要修改其他认证页。

## 尺寸与间距

- 画板：1440 × 900。
- 左侧视觉区：814 × 938，起点 `x=-14, y=0`。
- 右侧区域：640 × 900，起点 `x=799, y=0`。
- 表单面板：530.3 × 727，距离右侧区域左边 56、顶部 86。
- 表单主控件宽：430.4。
- 页面标题：32 px / Bold；页面说明：16 px / Regular。
- 字段标签：20 px / Bold；输入内容：15 px / Regular。
- 辅助说明：13–14 px / Regular。
- 主按钮高度：34 px；表单控件圆角：8 px；表单容器圆角：24 px。
- 页面画板整体透明度固定为 `100%`，颜色由画板内部图层控制。

## 页面差异

- 密码可见页：使用明文密码，保留密码显示/隐藏图标及隐藏密码热点。
- 登录成功页：使用身份卡片、课程列表、进入工作台与切换账号按钮，以及唯一一组角色演示入口。
- 找回密码：按验证方式、验证码、新密码、确认新密码和重置操作分组。
- 账号受限：按账号状态、操作按钮和安全提示分组。

## 交互闭环

- 登录 → 登录 · 密码可见 → 登录
- 登录 / 密码可见 → 统一身份认证回调
- 登录 / 密码可见 → 找回密码 → 登录
- 登录与密码可见页面不提供“账号受限”入口，受限页面不进入主登录链路
- 统一身份认证回调 → 进入工作台（当前学生账号）
- 统一身份认证回调 → 学生 / 教师 / 运维端 3 个角色入口
- 教师和运维端入口通过节点链接打开各自独立的 27 屏路线页
- 统一身份认证回调 → 切换账号 → 登录
- 账号受限与权限申请 → 申请临时访问权限 → 角色与权限管理
- 页面画板和大面积背景不设置点击动作，仅明确按钮、文字链接和角色入口触发跳转。
- “忘记密码？”文字及对应热区均跳转到找回密码页面。
