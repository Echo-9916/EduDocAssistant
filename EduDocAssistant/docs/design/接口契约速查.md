# 接口契约速查

> 精简自《详细设计说明书》§2.3/§5.1/§5.3/§4.4，供前后端实现对齐。代码落地见 `common/api/`。

## 1 统一响应 envelope

所有 REST 接口返回：

```json
{
  "code": 200,
  "message": "success",
  "data": {},
  "traceId": "2f6b...",
  "timestamp": "2026-10-31T04:00:00Z"
}
```

- `code`：业务码，成功固定 `200`；HTTP 状态由接口语义决定（查询 200、创建 201、删除 204）。
- `message`：成功 `success`；失败为错误码默认提示或自定义提示。
- `data`：业务数据，失败为 `null`。
- `traceId`：从请求头 `X-Trace-Id` 透传，缺省由服务端生成并回写响应头。
- `timestamp`：UTC ISO-8601（`Instant`）。

## 2 错误码

| 业务 code | HTTP | 含义 |
| --- | --- | --- |
| 200 | 200/201/204 | 成功 |
| 40001 | 400 | 参数校验失败 |
| 40101 | 401 | 未登录或令牌过期 |
| 40102 | 401 | 令牌已撤销 |
| 40301 | 403 | 角色权限不足 |
| 40302 | 403 | 文档 ACL 拒绝 |
| 40303 | 403 | 共享链接过期或撤销 |
| 40401 | 404 | 资源不存在或不可见 |
| 40501 | 405 | 请求方法不允许（1103 审查整改新增，已同步《详细设计说明书》§5.1） |
| 40901 | 409 | 版本或并发冲突 |
| 40902 | 409 | 重复提交或幂等键冲突 |
| 41301 | 413 | 文件超过 20MB |
| 41501 | 415 | 文件类型不支持 |
| 42201 | 422 | 文档结构无法解析 |
| 42202 | 422 | 格式校验存在阻断问题 |
| 42901 | 429 | 请求或任务并发超限 |
| 50001 | 500 | 服务器内部错误 |
| 50201 | 502 | 模型服务失败 |
| 50301 | 503 | OSS 或数据库暂时不可用 |
| 50401 | 504 | 处理超时 |

## 3 请求约定

- 路径前缀 `/api/v1`；身份令牌放 `Authorization: Bearer <token>`。
- 所有请求透传 `X-Trace-Id`（前端生成 UUID）。
- 分页：`page`（从 1 起）、`pageSize`、`sort`；响应用 `PageResult{items,total,page,pageSize}`。
- 幂等写操作（创建上传会话、完成上传、创建 AI 任务、提交作业、创建导出任务）必须带 `Idempotency-Key`。
- 前端按 §2 错误码做客户端处理：40101→跳登录并保留回跳；40301/40302→无权限态；5xx→展示 traceId。

## 4 公共类型

- `ApiResponse<T>`：见 §1。
- `PageResult<T>`：`{items: T[], total: long, page: int, pageSize: int}`。
- `UserPrincipal`：`{userId, roles, courseScope}`（请求上下文，认证任务 F-03 落地）。

## 5 文档域接口（02 切片落地，含 B-02 要求回填的契约外辅助接口）

| Method / Path | 权限点 | Idempotency-Key | 成功返回 | 说明 |
| --- | --- | --- | --- | --- |
| `GET /api/v1/courses` | 认证即可，无权限点 | 否 | 200 `[{id,courseCode,courseName,termCode,memberRole}]` | **契约外辅助接口**（B-02 回填）：上传表单与列表筛选的课程数据源 |
| `POST /api/v1/documents/upload-sessions` | DOCUMENT_CREATE | 是 | 201 `{sessionId,objectKey,bucket,region,endpoint,sts{…}}` | 校验 20MB/类型双验/课程成员；STS 900s，inline policy 收窄到单 objectKey；`region` 为阿里云地域名、`endpoint` 为 OSS 端点，**直传用 endpoint** |
| `POST /api/v1/documents/upload-sessions/{id}/complete` | DOCUMENT_CREATE | 是 | 201 `{documentId,versionId}` | 服务端实算 SHA-256 比对；单事务五写+审计；COMPLETED 会话换 key 重放返回原结果 |
| `GET /api/v1/documents` | DOCUMENT_READ | 否 | 200 `PageResult<DocumentSummary>` | 强制 owner=当前用户；筛选 courseId/type/status/keyword；默认排除 DELETED，`status=DELETED` 查回收站 |
| `GET /api/v1/documents/{id}` | DOCUMENT_READ | 否 | 200 `DocumentDetail` | 非 owner → 40401（不泄露存在性） |
| `DELETE /api/v1/documents/{id}` | DOCUMENT_DELETE | 是 | 204 | 软删，`purge_at=+30d`，不动 OSS |
| `POST /api/v1/documents/{id}/restore` | DOCUMENT_DELETE | 是 | 204 | 仅 DELETED；恢复态按分块有无推 READY/FAILED；撞同名 → 40901 |
| `POST /api/v1/documents/{id}/parse` | DOCUMENT_EDIT | 是 | 200 `{taskId}` | 仅 READY/FAILED；body `{versionId?}`（仅允许当前版本）；taskId=outbox eventId hex |

- 错误码补充：会话过期/不存在 40401 · 非本人会话 40301 · 大小/哈希不符 40901 · 同名（含回收站）40901 · 未直传 complete 40901。
- 权限映射说明：restore/parse 无专属权限点，分别复用 DOCUMENT_DELETE / DOCUMENT_EDIT（任务文档 B-08 记录）。

## 6 课程与作业域接口（06 切片 1 落地）

路径按角色前缀收口：教师 `/api/v1/teacher/*`、学生 `/api/v1/student/*`。与 `/courses`（精简下拉）、`/ops/courses`（治理视角）是三个不同集合，勿混用。

| Method / Path | 权限点 | Idempotency-Key | 成功返回 | 说明 |
| --- | --- | --- | --- | --- |
| `GET /api/v1/teacher/courses` | ASSIGNMENT_MANAGE | 否 | 200 `PageResult<TeacherCourseView>` | 可见范围=本人任 TEACHER 的课程成员；`groups` 取 `COUNT(DISTINCT group_name)` |
| `POST /api/v1/teacher/courses` | ASSIGNMENT_MANAGE | 是 | 201 `TeacherCourseView` | 同 code+term → 40902；**创建者自动登记为该课 TEACHER 成员**，否则 courseScope 连自己都看不见 |
| `POST /api/v1/teacher/courses/{courseId}/member-imports` | ASSIGNMENT_MANAGE | 是 | 200 `{total,created,activated,conflicts,failures[]}` | 行数据由前端提交（**不解析 CSV**）；无账号学生建 `account_status='I'` 未激活账号 |
| `GET /api/v1/teacher/assignments` | ASSIGNMENT_MANAGE | 否 | 200 `PageResult<AssignmentView>` | 含 `expected/submitted/unsubmitted/overdue/graded/formatIssues` 与 `rubric[]`；只列本人课程 |
| `POST /api/v1/teacher/assignments` | ASSIGNMENT_MANAGE | 是 | 201 `{id,status}` | `draft=true→DRAFT`；`allowLate/requireFormatCheck` 省略按 `'N'` 兜底；`rubric` 存 `rubric_json`；主键由应用侧生成（同课重名合法） |
| `GET /api/v1/teacher/assignments/{id}/unsubmitted` | ASSIGNMENT_MANAGE | 否 | 200 `{items[{accountNo,name}]}` | 只读名单；**提醒投递随消息切片**，本端点不发消息 |
| `GET /api/v1/teacher/submissions` | SUBMISSION_READ | 否 | 200 `PageResult<SubmissionView>` | 每生取 `MAX(attempt_no)`；`items[]` 由 `score_json` 解析 |
| `PUT /api/v1/teacher/submissions/{id}/grade` | ASSIGNMENT_MANAGE | 是 | 200 `{score,status:"GRADED"}` | 分项键=评分项名；**总分服务端求和**，缺项/超分/多项 → 40001 |
| `GET /api/v1/teacher/workbench-summary` | ASSIGNMENT_MANAGE | 否 | 200 `{dueThisWeek,pendingGrade,formatIssues,collabActive,priority[]}` | `collabActive` 恒 0（协作统计随切片 3） |
| `GET /api/v1/student/assignments` | SUBMISSION_SELF_READ | 否 | 200 `PageResult<StudentAssignmentView>` | 只含 PUBLISHED/CLOSED；四态与 `remainText` 由服务端派生 |
| `POST /api/v1/student/assignments/{id}/submissions` | DOCUMENT_CREATE | 是 | 201 `{submissionId,attemptNo,status}` | 顺序：ID 格式→课程成员→DRAFT 拒→文档归属+READY→迟交判定；冻结 `document_version_id` |

- 错误码口径：越权 40301 · 不存在/非本人 40401 · 参数 40001 · 状态冲突（关闭/超期禁迟交）40901 · 唯一约束 40902。
- `require_format_check='Y'` 本期**不**做提交前同步阻断（校验结果异步产出），见 `docs/tasks/06-待确认清单.md` A4。

## 7 审计查询接口（06 切片 1 落地，REQ-09）

| Method / Path | 权限点 | 成功返回 | 说明 |
| --- | --- | --- | --- |
| `GET /api/v1/ops/audit-events` | AUDIT_READ **+ ROLE_OPS** | 200 `PageResult<AuditEventView>` | `range∈24h/7d/30d`（缺省 24h，非法 40001）；`occurredAt` 为 UTC ISO 带 `Z`；`riskLevel` 按同操作人窗口内 FAIL 数现算（≥2 HIGH） |
| `GET /api/v1/ops/audit-events/{eventId}` | AUDIT_READ + ROLE_OPS | 200 `AuditEventDetailView` | `chain` 按同 `trace_id` 聚合并稳定排序；`advice` 按结果码给固定文案 |

- `/api/v1/ops/**` 在 SecurityConfig 里额外要求 `ROLE_OPS`：`AUDIT_READ` 历史上也授过 TEACHER，而教师审计视图按需求应是「所授课程」，该视图未实现，故先收回全库可见（见待确认清单 B1）。
- 成功码兼容 `'200'` 与 `'SUCCESS'`（既有写入链路两种都写过）。
